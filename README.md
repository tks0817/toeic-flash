# TOEIC Flash v35 — 学習画面の操作性改善

- iPhone Safariのダブルタップ拡大を抑止するため `touch-action: manipulation` を適用。ピンチ操作による拡大は残し、アクセシビリティを確保。
- 「学習時間」タブを新設。学習時間・累計・リセット・学習状況の3つの統計をこの画面へ移動。
- 「学習」タブにはフラッシュカードを表示。時間の表示までスクロールする必要をなくした。
- ナビゲーションを5タブに調整。
- 設定画面のバージョンをv35に更新。
- 既存の学習記録（IndexedDB）や時間（localStorage）の保存キーは変更なし。

注意: iPhone 13での実機動作は未検証。更新前に暗号化バックアップを取得。日本語OCR・手書き認識などは引き続き検証・開発が必要です。
