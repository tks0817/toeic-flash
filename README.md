# TOEIC Flash v41 — OCR取得エラーの切り分けと認識改善の土台

- Tesseract.js v5.1.1のスクリプトとワーカーにcdnjs配布元を追加。
- CSPのscript-srcにWebAssembly実行用 `wasm-unsafe-eval` とcdnjsを追加。
- 診断エラーに「スクリプト取得」「ワーカー/WASM/言語データ準備」等の失敗段階を表示。
- 日本語・英語OCRの試験用画像による診断を維持。
- 外部に写真や学習履歴をアップロードする処理はありません。外部CDNのコードは初回に取得するため、そのコードの信頼性には依存します。

**未検証:** iPhone 13 Safari実機でのOCR成功、認識精度、完全オフライン動作。手書き・下線・写真1枚からの完全自動カード登録は未完成。

更新前に暗号化バックアップを取り、GitHub公開リポジトリへ教材写真・学習記録を置かないでください。
