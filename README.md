# TOEIC Flash v31 — iPhone Safari向けOCR動作診断と画像補正

- 「日本語OCR動作診断」ボタンを追加。アプリ内で「apple りんご」のテスト画像を作り、英語と日本語が実際に認識できるか別々に判定します。写真・学習記録は送信しません。
- 小さな文字のOCRを改善するため、元画像の解像度が低い場合は最大2倍まで拡大して認識します（最大1800×2200px）。
- 同じ写真でOCRを繰り返しても、完全一致する認識結果を貼り付け欄へ重複追加しません。
- 学習データのIndexedDBと暗号化バックアップ方式は維持。

## 注意
OCR部品は初回インターネット接続で外部配布元から取得します。**iPhone 13 Safariでの動作は未検証**。日本語の診断が成功しても教材写真の精度、手書き文字、下線照合、完全自動登録は保証しません。手書き・下線の自動認識は未実装です。公開GitHubへ教材画像を置かず、更新前に暗号化バックアップを取得してください。
